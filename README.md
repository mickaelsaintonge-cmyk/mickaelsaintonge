# Mickael Saintonge — Site officiel

Site du salon de coiffure Mickael Saintonge, Paris 8e.

## Déploiement

Ce site est déployé automatiquement sur Vercel à chaque push sur la branche `main`.

## Structure

```
index.html   → Site complet (one-page)
vercel.json  → Configuration Vercel
```

## Réservation

La réservation en ligne est gérée via Planity (modale intégrée).
